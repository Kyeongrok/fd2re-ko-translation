# FD2Re 한국어 번역 패치

중국어 동인 게임 **FD2Re** (Flame Dragon X Re; v0.0.1, Unity 2021.3.13)를
한국어로 즐기기 위한 XUnity.AutoTranslator 기반 번역 패치입니다.

> 게임 본체는 본 저장소에 포함되어 있지 않습니다. 원작자의 배포처에서 직접 받으세요.
> 본 패치는 비상업 동인 작품에 대한 비공식 팬 번역입니다.

## 무엇이 들어 있나

- `BepInEx/Translation/ko/Text/_AutoGeneratedTranslations.txt`
  XUnity.AutoTranslator가 읽는 번역 사전 (876개 엔트리, 게임 내 거의 모든 텍스트 커버)
- `BepInEx/config/AutoTranslatorConfig.ini`
  참고용 설정. `Language=ko`, `FromLanguage=zh-CN`로 미리 맞춰져 있음
- `source/translations_phase1.py`
  이름/UI/아이템/마법/직업 등 짧은 라벨의 번역 사전 (Python dict)
- `source/translations_phase2.py`
  대사 라인의 번역 사전 (Python dict)
- `source/build_xunity.py`
  phase1 + phase2를 합쳐 `_AutoGeneratedTranslations.txt`를 생성하는 빌더
- `tools/`
  게임 .assets/.bundle에서 원문을 다시 추출할 때 쓰는 스크립트들 (UnityPy/dnfile 필요)

## 설치 방법

### 1) 사전 준비물 받기

1. **BepInEx 5 (x64)** — Unity 플러그인 로더
   https://github.com/BepInEx/BepInEx/releases (`BepInEx_win_x64_5.4.23.x.zip`)
2. **XUnity.AutoTranslator (BepInEx 5용)** — 번역 플러그인
   https://github.com/bbepis/XUnity.AutoTranslator/releases
   (`XUnity.AutoTranslator-BepInEx-5.x.x.zip`)

### 2) 게임 폴더에 BepInEx + XUnity 설치

1. 게임 루트(`FD2Re.exe`가 있는 위치)에 BepInEx zip을 압축 해제
2. 같은 위치에 XUnity zip을 압축 해제 (덮어쓰기)
3. `FD2Re.exe`를 한 번 실행 → 메인 메뉴 보고 종료
   (`BepInEx/config/AutoTranslatorConfig.ini` 자동 생성됨)

### 3) 본 저장소의 한국어 번역 적용

이 저장소를 클론한 뒤, `BepInEx/` 폴더 내용을 게임의 `BepInEx/`에 통째로 덮어쓰기:

```
fd2re-ko-translation/BepInEx/Translation/ko/Text/_AutoGeneratedTranslations.txt
  → 게임폴더/BepInEx/Translation/ko/Text/_AutoGeneratedTranslations.txt
```

`AutoTranslatorConfig.ini`는 본인이 이미 다른 설정을 만져둔 게 없다면 같이 덮어써도
됩니다. 따로 만져둔 게 있다면 `[General]` 섹션의 두 줄만 맞춰주면 됩니다:

```ini
[General]
Language=ko
FromLanguage=zh-CN
```

### 4) 게임 실행

`FD2Re.exe` 실행. 인터넷 연결이 필요한 자동 번역과 달리, 본 패치는 오프라인으로도
미리 번역된 텍스트를 그대로 표시합니다.

## 번역 수정/기여

번역 결과가 어색한 부분이 있으면 두 가지 방법으로 고칠 수 있습니다.

### 빠른 수정 (한 줄 고치기)

`BepInEx/Translation/ko/Text/_AutoGeneratedTranslations.txt`에서 해당 라인을
직접 편집 → 게임 안에서 `ALT+R`로 즉시 리로드.

### 본격 기여 (PR로 올릴 때)

1. `source/translations_phase1.py` 또는 `translations_phase2.py`의 dict를 수정
2. `python source/build_xunity.py` 실행 → txt가 다시 생성됨
3. phase 파일 + 갱신된 txt 두 개 모두 커밋

phase1은 짧은 라벨 (이름/아이템/UI), phase2는 긴 대사로 분리되어 있습니다.

## 게임 내 단축키 (XUnity)

| 키 | 동작 |
|---|---|
| `ALT+T` | 원문 ↔ 번역 토글 |
| `ALT+0` (숫자 영) | XUnity 설정 UI |
| `ALT+R` | 번역 파일 리로드 |

## 라이선스

번역 텍스트(이 저장소가 새로 만든 결과물)는 자유롭게 가져다 쓰셔도 됩니다.
다만 게임 원본 텍스트(중국어 키)와 게임 자체의 저작권은 원작자에게 있습니다.
원작자가 비상업 사용을 명시했으므로 본 패치도 비상업 용도로만 사용하세요.
