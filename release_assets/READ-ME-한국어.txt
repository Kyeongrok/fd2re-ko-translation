FD2Re 한국어 번역 패치 (통합판)
================================

설치 방법 — 정말 간단합니다!
-----------------------------

1. 이 zip 파일의 내용물 전부를 게임 폴더(FD2Re.exe가 있는 폴더)에
   그대로 압축 해제하세요. 예: C:\Games\FD2Re\

2. FD2Re.exe 실행. 끝.

처음 실행 시 검은 콘솔 창이 같이 뜨면서 BepInEx + XUnity가 로드되고,
바로 한국어로 표시됩니다.


무엇이 들어 있나
----------------

- BepInEx 5.4.23.x (Unity 게임 플러그인 로더, LGPL-2.1)
- XUnity.AutoTranslator 5.6.x (실시간 번역 플러그인, MIT)
- 본 한국어 번역 사전 (876개 엔트리, 게임 내 거의 모든 텍스트 번역)


게임 안에서 쓸 수 있는 단축키
------------------------------

- ALT+T : 원문(중국어) ↔ 번역(한국어) 토글
- ALT+R : 번역 파일 다시 읽기 (txt 직접 편집했을 때)
- ALT+0 (숫자 영) : XUnity 설정 UI


콘솔 창 끄기 (선택)
--------------------

게임 실행할 때 검은 콘솔 창이 거슬리면, 게임 폴더의
BepInEx\config\AutoTranslatorConfig.ini 파일을 메모장으로 열어
[Debug] 섹션의

    EnableConsole=True

을 다음으로 바꾸세요:

    EnableConsole=False


번역 수정/제보
---------------

- 어색한 번역은 BepInEx\Translation\ko\Text\_AutoGeneratedTranslations.txt
  에서 해당 줄을 직접 편집할 수 있습니다.
- 편집 후 게임 안에서 ALT+R 누르면 즉시 반영.
- 정식 PR은 GitHub에서:
  https://github.com/Kyeongrok/fd2re-ko-translation
